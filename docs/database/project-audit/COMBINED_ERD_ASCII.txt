  PK                        Primary Key (Surrogate UUID v4 in all 10 entities)
  FK                        Foreign Key (Referential integrity constraint)
  UK                        Unique Key Constraint (@unique in Prisma schema)
  === [ 1 ] === [ N ] ==>   Database-Enforced Foreign Key Relation (Solid Line)
  ... [ 1 ] ... [ N ] ...>  Application-Level Soft Relationship (Dashed Line)
